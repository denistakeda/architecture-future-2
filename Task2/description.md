# Домены

### Организация

Центральный домен. Сюда стекаются финансовые показатели со всех бизнес линий. Обезличенная информация о клиентах и сотрудниках. Благодаря этому домену компания может отслеживать ключевые бизнес показатели. Планировать дальнейшую стратегию развития компании.

### Фармацевтика

Отдельный домен для проведения аналитики по фармацевтической деятельности. За счет изолированности может развиваться отдельно от других бизнес линий

### Медиценское оборудование

Отдельный домен для проведения аналитики по медицинскому оборудованию. За счет изолированности может развиваться отдельно от других бизнес линий

### Финтех

Отдельный домен для проведения аналитики по финтех продуктам. За счет изолированности может развиваться отдельно от других бизнес линий

### Клиника

Отдельный домен для проведения аналитики по клиникам. За счет изолированности может развиваться отдельно от других бизнес линий. Не содержит мединской информации, так как компания не планирует проводить аналитику по медицинским данным клиентов

### Клиенты

Домен для хранения информации от клиентах. Агрегирует информацию о клиентов всех бизнес линий. Скрывает от других доменов чуствительную информацию. Позволяет проводить сегментацию клиентов

### Сотрудники

Домен для хранения кадровой информации.  Агрегирует информацию о сотрудниках всех бизнес линий. Скрывает от других доменов чуствительную информацию
